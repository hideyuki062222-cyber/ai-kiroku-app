# 介入度の復元・普通／長めの整理・直前同文の改善

比較元はmain 23c5246f58a677c678a296cc1b9b12c5747723e5（PR #30公開済み）。11月12日前後の旧画面が使う固定HTMLのinterventionLevelを調査し、5つの値・選択肢と既存intervention_level列との対応を復元しました。

## 介入度の選択と保存

| 保存値 | 復元した選択肢 |
|---|---|
| active | 積極的支援（直接介助を多め） |
| partial | 必要な部分を介助 |
| prompt | 声かけ・促し中心 |
| watch | 見守り中心 |
| minimal | 最小限の支援・確認中心 |

画面には「今回の支援介入度（任意）」を直接表示します。未選択でも作成でき、選択したときだけ今回の支援の範囲を②へ1回記載します。安全確認・本人の自立・具体的介助・反応は、介入度だけから補完しません。サービスを選び直す操作や、介入度に応じた具体的介助の自動チェックはありません。

既存のintervention_levelへ同じ値を保存し、daily_factsにも含めます。保存済み履歴では介入度の日本語表示を再表示します。未登録の過去記録はそのままとし、推測して埋めません。再読み込み・利用者切替後の新規入力は未選択に戻し、過去の介入度を当日の事実へ流用しません。

旧版の必須指定と、本人の反応・安全確認等を加える旧文章は復元していません。旧5値を受け付ける既存DB制約を維持し、SQL変更は不要です。

## 普通・長めの文章例

架空利用者の同じ入力（訪問時は椅子に座り、右膝の痛みを訴え、普段より動作がゆっくり。服薬への声かけ、うなずき、ゆっくりした説明、支援後は椅子に座り、水分の希望）を使った生成例です。服用を確認していないため服用済みにはしません。

### 短め

① 訪問時、椅子・座椅子に座っておられ、落ち着いて過ごされていました。痛みの訴えがありました。本人から「右膝が痛い」との発言・訴えがありました。普段との違いとして、普段より動作がゆっくりでした。

② 指示内容確認しました。前回のサービス記録確認しました。今回は必要な部分に介助を行いました。服薬に向けて声をかけると、本人はうなずいて応じられました。ゆっくり話しました。支援後は、椅子に座って過ごされました。本人から水分の希望があった。

### 普通

① 訪問時、椅子・座椅子に座っておられ、落ち着いて過ごされていました。痛みの訴えがありました。本人から「右膝が痛い」との発言・訴えがありました。普段との違いとして、普段より動作がゆっくりでした。

② 指示内容確認しました。前回のサービス記録確認しました。今回は必要な部分に介助を行いました。
服薬に向けて声をかけると、本人はうなずいて応じられました。ゆっくり話しました。支援後は、椅子に座って過ごされました。本人から水分の希望があった。

### 長め

① 【訪問時の状態】
椅子・座椅子に座っておられました。落ち着いて過ごされていました。
【体調】
痛みの訴えがありました。
【本人の発言・訴え】
本人から「右膝が痛い」との発言・訴えがありました。
【普段との違い】
普段より動作がゆっくりでした。

② 指示内容確認しました。前回のサービス記録確認しました。
今回は必要な部分に介助を行いました。
【服薬介助・確認】
職員の支援：服薬に向けて声をかけると、本人はうなずいて応じられました。ゆっくり話しました。
支援後の状態：支援後は、椅子に座って過ごされました。
補足：本人から水分の希望があった。

長めでは、入力のある状態・体調・発言・普段との違い、サービス別の本人の自立部分・職員の支援・反応・支援後・補足を区切ります。入力がない見出しや、未確認の事実は追加しません。普通は支援ごとの自然な段落、短めは内容を落とさず接続する形式を維持します。文字数を満たすための定型的な観察文・水増しは加えません。

### 入浴・本人の自立部分と職員の介助を分けた長めの例

① 【訪問時の状態】
椅子・座椅子に座っておられました。落ち着いて過ごされていました。

② 指示内容確認しました。前回のサービス記録確認しました。
今回は必要な部分に介助を行いました。
【入浴介助】
本人が行ったこと：上半身は本人が自分で洗われました。
職員の支援：職員は下肢の洗身を介助しました。本人のペースに合わせて待ちました。
本人の反応：本人は声かけにうなずいて応じられました。
支援後の状態：支援後は、椅子に座って過ごされました。

## 同文反復の原因と改善

以前は同じ入力を固定の表現に変換していました。PR #30の回数に応じた表現選択は復元済みですが、全候補が過去記録に存在すると、最大類似度が同点になり、直前と同じ訪問文が優先される場合がありました。また連続32 seedの候補では、入力が多いと支援文側の選択桁まで変化が届きにくい問題がありました。

今回は直前の同一職員・施設・利用者の生成文との一致を別に評価し、過去の最大類似度が同点でも、直前の訪問文・支援文の反復を避けられる候補を優先します。候補seedを離れた位置にも分散させ、最大32候補の中で構成・同義表現を検討します。候補は既存の事実からのみ作り、引用・補足の原文は書き換えません。類似が残っても通常保存を妨げません。

同一事実・既知の表現を含む固定履歴を使い、1,000回連続生成した比較（隣接999組）では、訪問文の直前完全一致は修正前999組→修正後0組でした。支援文・全文の直前一致は両版とも0組でした。修正後でも過去全期間では同じ表現が再び現れます。この比較は前回と連続する同文の改善を測ったもので、1,000種類の一意な文章や日々の変化を保証するものではありません。
