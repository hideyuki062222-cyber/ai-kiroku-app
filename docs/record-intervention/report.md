# PR #31：介入度復元と文章生成の最終調整（2026年11月21日）

比較元はmain 23c5246f58a677c678a296cc1b9b12c5747723e5（PR #30公開済み）。11月12日前後の旧画面が使う固定HTMLのinterventionLevelを調査し、5つの値・選択肢と既存intervention_level列との対応を復元しました。

## 介入度の選択と保存

| 保存値 | 復元した選択肢 |
|---|---|
| active | 積極的支援（直接介助を多め） |
| partial | 必要な部分を介助 |
| prompt | 声かけ・促し中心 |
| watch | 見守り中心 |
| minimal | 最小限の支援・確認中心 |

画面には「今回の支援介入度（任意）」を直接表示します。未選択でも作成でき、選択したときだけ今回の支援の範囲を②へ1回記載します。安全確認・本人の自立・具体的介助・反応は、介入度だけから補完しません。サービスを選び直す操作や、介入度に応じた具体的介助の自動チェックはありません。

既存のintervention_levelへ同じ値を保存し、daily_factsにも含めます。保存済み履歴では介入度の日本語表示を再表示します。未登録の過去記録はそのままとし、推測して埋めません。再読み込み・利用者切替後の新規入力は未選択に戻し、過去の介入度を当日の事実へ流用しません。

旧版の必須指定と、本人の反応・安全確認等を加える旧文章は復元していません。旧5値を受け付ける既存DB制約を維持し、SQL変更は不要です。

## 今回の最終調整

前回の30回テストでは、長めの支援文が2種類だけでした。長めの処理が文章を見出し・固定順序で作り直し、生成した一部の候補を捨てていたことに加え、無関係な過去記録との弱い文字一致まで最小化したため、少数の文面に偏っていました。

- 長めを見出し中心から文章中心に変更しました。本人の自立部分と職員の介助を明示し、入力された支援方法・本人の反応・支援後の状態・補足を保持します。
- 声かけとそれに対する反応が両方入力されている場合に限り、自然な接続・主語・語順の候補を追加します。本人の自立部分と職員の支援、支援方法の記述位置にも、安全に交換できる構成を用意しました。
- 構成の選択を文言選択から分離し、長めの構成が表現候補を打ち消さないようにしました。入力とseedに基づく決定的な選択で、事実や日々の変化をランダム生成しません。
- 過去記録の候補評価は、既存の類似警告の基準（介助文0.82以上・加重0.8以上）に合わせました。無関係な記録との弱い文字一致は候補を偏らせず、本当の完全一致・類似には引き続き候補探索を行います。参照する施設・利用者・RLS・直近300件の取得方法は変更していません。
- 服用未確認は独立した文として保持し、介助方法等と不自然に接続しません。拒否・未確認を服用済みにしません。自由記載・引用は言い換えません。

入力UI・15サービス・介入度の選択・必須入力は今回変更していません。通常の最小操作モデルは従来どおり生成6操作、介入度も選ぶ場合8操作、正式保存は＋1操作です。選択欄を開く＋選ぶを2操作として数えた机上モデルで、ログイン・スクロール・実機所要時間を含みません。今回の修正による追加操作は0です。

## 同じ入力を30回生成した比較

固定条件：同じ架空利用者・同じ施設・同じ職員、服薬介助、介入度「声かけ・促し中心」。椅子に座る・笑顔・服薬の声かけのみ（服用未確認）・うなずき・ゆっくり話す・支援後は椅子、を入力。無関係な架空の保存済み記録1件を固定し、各モードを新しいページで開始。30回の間に正式保存はしません。直前の生成文は実際の画面の仕組みで参照します。

| 長さ | 対象 | 種類数：前→後 | 完全一致の再出現：前→後 | 直前との一致：前→後 |
|---|---|---:|---:|---:|
| 普通 | 訪問時の状態 | 9→14 | 21→16 | 0→0 |
| 普通 | 介護者の実施内容 | 4→12 | 26→18 | 0→0 |
| 長め | 訪問時の状態 | 3→11 | 27→19 | 0→0 |
| 長め | 介護者の実施内容 | 2→20 | 28→10 | 0→0 |

再出現＝30回から種類数を引いた値です。句読点・空白・改行も含む実際の出力文字列を比較し、正規化していません。完全一致する全組合せ（435組）の数もJSONに保存しています。訪問文＋支援文の組合せは普通30種類（重複0回）、長め29種類（重複1回）でした。

実固定HTML・実SDK・隔離Postgresを通したブラウザ操作で、PC幅1440px・スマホ幅390pxそれぞれ普通30回／長め30回を実行し、両幅で全出力・集計が一致しました。通常の作成ボタンを使い、毎回の入力値が同一であることも検証しました。[各回の全文・集計・入力・対象ソースのSHA-256](thirty-comparison.json)。

文面は有限です。過去全体での重複ゼロ・毎日の支援内容の変化は保証しません。同じ事実なら類似しても通常保存でき、手修正は強制しません。これは固定した1ケースの集計で、すべての入力・履歴で同じ種類数になるわけではありません。
